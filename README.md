# Танцевальный тренер — Pro

PWA для учёта клиентов, занятий и клубных групп у преподавателя танцев.
Один HTML-файл без сборки. Эта ветка добавляет **платную подписку Pro**
с лимитами бесплатной версии.

**Живая версия:** https://taoo1997-oss.github.io/calendar-for-trainer-pro/

> Отдельный репозиторий от рабочего `calendar-for-trainer` — чтобы правки по
> подписке не задели то, чем уже пользуются, и чтобы это был сайт, а не
> одинокий html-файл.

## Что бесплатно, что по подписке

| Раздел | Бесплатно | Pro |
|---|---|---|
| Клиенты | до 10 | без ограничений |
| Занятия в день | до 4 | без ограничений |
| Члены клуба | до 20 | без ограничений |
| Группы клуба | до 2 | без ограничений |

Цена: **200 ₽ / ≈ 2 € в месяц**. Приём денег пока **не подключён** (ждём
оформления самозанятости) — способы оплаты показаны как витрина, Pro
включается тестовой кнопкой в Настройках. Подробности —
в папке `оплата/` основного проекта.

## Разработка

Сборки нет. Открыть `index.html` в браузере — уже работает.

```
npm test        # юнит-тесты логики лимитов (node --test, без зависимостей)
```

## Структура

```
index.html                    всё приложение
sw.js                         service worker (offline shell)
tests/subscription.test.mjs   тесты лимитов подписки
.nojekyll                     чтобы GitHub Pages не трогал файлы
```

## Деплой

GitHub Pages из ветки `main`, корень репозитория. `git push` — и через
минуту новая версия на том же адресе. При каждой правке `index.html`
поднимать `CONFIG.BUILD` и `CACHE` в `sw.js` (иначе браузеры отдадут кэш).
